# R&R Limpezas

Landing page da R&R Limpezas, empresa de limpeza pos-obra.

Site: https://rerlimpezas.com.br/posobra/

## Sobre o projeto

Landing page desenvolvida sob demanda para apresentar os servicos de limpeza pos-obra da empresa e gerar contato via WhatsApp/formulario de orcamento.

Projeto desenvolvido por Nicolas Souza (https://devnicolas.vercel.app/) - Arrow Shot.
